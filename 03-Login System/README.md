# Login System

A simple command-line registration and login system built with Python.

## Features

* Register a new user
* Prevent duplicate usernames
* Validate empty usernames
* Validate empty passwords
* Login using username and password
* Check incorrect usernames
* Check incorrect passwords
* Store registered users in a text file
* Load existing users when the application starts
* Handle invalid menu input

## Concepts Practiced

* Classes and objects
* Constructors
* Lists
* File handling
* Reading and writing text files
* Exception handling
* User input validation
* Conditional logic
* Searching through objects
* Menu-driven programs

## Data Storage

User information is stored in:

`users.txt`

## Security Note

This is an educational project designed to practice Python fundamentals.

Passwords are stored as plain text for learning purposes. This implementation should **not** be used for a real authentication system.

A production authentication system should use secure password hashing and appropriate authentication practices.

## Technologies

* Python
* Object-Oriented Programming
* Text file handling

## Purpose

This project was built to practice Object-Oriented Programming, file handling, exception handling, input validation, and basic authentication logic.
