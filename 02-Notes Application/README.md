# Notes Application

A command-line notes application built with Python using Object-Oriented Programming and file handling.

## Features

* Add new notes
* View saved notes
* Search notes using keywords
* Delete notes
* Automatically record the date and time of notes
* Save notes to a text file
* Load existing notes when the application starts

## Concepts Practiced

* Classes and objects
* Constructors
* Methods and attributes
* Lists
* File handling
* Reading and writing text files
* Exception handling
* Date and time using `datetime`
* Searching with strings
* CRUD-style operations
* Menu-driven programs

## Data Storage

Notes are stored in:

`notes.txt`

Each note contains:

* Note ID
* Note text
* Date and time

## Technologies

* Python
* `datetime`
* Text file handling

## Example

```text
=== NOTES APPLICATION ===

1. Add notes

4. Delete Notes
5. Exit

Enter your choice: 1

ID: 1
```

Example of viewing a saved note:

```text
ID: 1, Learn Python APIs, 2026-10-01 16:30:00
```


## Purpose

This project was built to practice Object-Oriented Programming, file handling, exception handling, and working with persistent data in a practical command-line application.
