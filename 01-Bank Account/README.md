# Bank Account

A simple command-line banking application built with Python.

## Features

* Create and manage bank accounts
* Deposit money
* Withdraw money
* Check account information
* Store account information using files

## Concepts Practiced

* Classes and objects
* Constructors
* Methods
* Encapsulation
* User input
* File handling
* Exception handling

## Technologies

* Python
* File handling

## Example

```text
===== BANK ACCOUNT =====

1. Create Account
2. Deposit
3. Withdraw
4. Check Balance
5. Exit

Enter your choice: 2
Enter amount to deposit: 5000

Amount deposited successfully.
```

## Purpose

This project was built to practice Object-Oriented Programming and file handling in Python through a practical command-line application.
